# Selora IDE

**The editor born connected to Selora.**

Selora IDE is an open-source code editor built on a Rust core with a React 18
+ TypeScript frontend, CodeMirror 6 for editing, and Tauri 2 rendering
through Microsoft Edge WebView2. It ships streaming chat, language-server
completions, and an approval-gated Agent Mode built on the
[Selora gateway](https://api.selora.lol) — first-class, not bolted on.

The design language is monochrome ink: dark canvas, hairline borders, calm
motion, functional green only. Tauri 2 + React 18 + CodeMirror 6, rendered in
WebView2.
