# Selora IDE

**The editor born connected to Selora.**

Selora IDE is an open-source code editor written in Rust, with streaming
chat, inline completions, and an approval-gated Agent Mode built on the
[Selora gateway](https://api.selora.lol) — first-class, not bolted on.

The design language is monochrome ink: dark canvas, hairline borders, calm
motion, functional green only. Pure Rust + [egui](https://github.com/emilk/egui) — no webview.
