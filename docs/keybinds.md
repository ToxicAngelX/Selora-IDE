# Keyboard shortcuts

The defaults (rebindable rows live in Settings → Keybinds):

| Action | Key |
|---|---|
| Open file | `Ctrl+O` |
| Open folder | `Ctrl+K Ctrl+O` |
| Save | `Ctrl+S` |
| Save all | `Ctrl+Shift+S` |
| Close editor | `Ctrl+W` |
| Close all editors | `Ctrl+K Ctrl+W` |
| Command palette | `Ctrl+Shift+P` |
| Fuzzy find | `Ctrl+P` |
| Go to symbol | `Ctrl+Shift+O` |
| Go to definition | `F12` |
| Hover | `Ctrl+K Ctrl+I` |
| Toggle chat | `Ctrl+L` |
| Toggle file tree | `Ctrl+B` |
| Toggle panel | `Ctrl+J` |
| Split editor | ``Ctrl+\`` |
| Settings | `Ctrl+,` |
| Find in file | `Ctrl+F` |
| Replace in file | `Ctrl+H` |
| Accept ghost text | `Tab` |
| Dismiss ghost text | `Esc` |
| Commit (git panel focused) | `Ctrl+Enter` |

Chords (`Ctrl+K Ctrl+O`) are two-stroke: press and release `Ctrl+K`, then
`Ctrl+O` within half a second.
